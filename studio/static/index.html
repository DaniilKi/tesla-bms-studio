03 / СОПРОТИВЛЕНИЕ ГРУПП

Оценка по двум измерениям ΔV/ΔI

Прямой сигнал внутреннего R из BMS не подтверждён. Расчёт ниже — кажущееся DC-сопротивление всей группы, не отдельной ячейки и не стандартный тест DCIR. Нагрузку приложение не создаёт.

Нет пары измерений. При постоянном токе сопротивление не рассчитывается.

На каждую группу: ≥2 отсчёта тока в пределах ±250 мс; разброс тока ≤2 А; возраст ≤5 с; |ΔI| ≥5 А; интервал 0.1–30 с. Проверки качества не заменяют метрологическую калибровку.
