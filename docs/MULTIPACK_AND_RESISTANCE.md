# 60–100 кВт·ч, Windows/Linux и сопротивление — версия 0.2

## Уточнённая задача

Поддерживать работу с батареями Model S линейки 60, 70, 75, 85, 90 и 100 кВт·ч, а не ограничивать продукт 85/90. Показывать напряжения групп и экспортировать данные о сопротивлении, сохраняя различие между прямым измерением BMS и расчётной оценкой. Предоставить онлайн-демо и локальный клиент для Windows/Linux.

Номинальная ёмкость — метаданные, а не декодер. Приложение не делает соответствие «60 = 84 группы» автоматически: существуют разные ревизии, ограничения ёмкости и замены блоков.

## Профили

| Настройка | Поведение |
| --- | --- |
| legacy83 | Окно 83 групп; 14 логических модулей, последняя группа неполная. Аппаратная топология требует проверки. |
| legacy84 | Окно 84 групп; 14 логических модулей. |
| legacy96 | Окно 96 групп; 16 логических модулей. |
| legacy_unknown | Просмотр до 96 позиций без заявления полного покрытия; сумма для сравнения блока и захват R отключены. |

Все профили — программные кандидаты для legacy S/X 2012–2020, не сертификат совместимости. Число свежих значений и кадры за пределами профиля видны в состоянии. Наличие последних каналов не доказывает отсутствие пропусков; автоматического определения только по максимальному mux нет. Температурная карта 28/32 каналов следует унаследованной гипотезе; независимой проверки для каждой ревизии нет. Протоколы S/X 2021+ требуют отдельного декодера.

В v0.2 исправлен масштаб 14-битного напряжения на `5/16384` В/отсчёт вместо округлённого `0.000305`. Формат `0x6F2`: mux 0..23, затем четыре 14-битных little-endian числа. Invalid-маркеры не освежают старые значения. Каждая группа стареет отдельно.

## Три разных сопротивления

1. **Внутреннее/кажущееся сопротивление группы, мОм.** Прямой общедоступный BMS-сигнал для всех заявленных батарей не подтверждён. Экспериментальная оценка строится по изменению V и I.
2. **VSH / сопротивление измерительной проводки.** Не является внутренним сопротивлением ячейки; отдельный протокол не реализован.
3. **Сопротивление изоляции HV, кОм.** Отдельное поле из `0x212`, byte 3 ×20, с invalid `0xFF`. Никогда не подставляется в колонку R группы.

## Метод оценки

При проверенном соглашении «разряд = положительный ток»:

`R_mΩ = −(V_B − V_A) / (I_B − I_A) × 1000`.

При противоположном соглашении знак тока инвертируется. Абсолютная величина не используется для сокрытия неверного знака.

Для каждой группы берутся её собственные отметки напряжения и ближайшего тока. Полный CAN-mux-цикл не считается одновременным измерением всех групп.

Программные фильтры:

- Одна сессия, источник, ёмкость и профиль; подтверждённые оператором условия и направление тока.
- Оба значения напряжения и тока конечны; возраст при захвате не более 5 с.
- Ток сопоставлен напряжению в пределах ±250 мс, есть минимум два отсчёта тока в этом окне; диапазон тока в окне не более 2 А.
- Разница токов не менее 5 А, разница времён напряжения 0.1–30 с.
- Если известны обе температуры, их изменение не более 2 °C; если известны оба SOC, изменение не более 1 процентного пункта. Неизвестные поля остаются пустыми.
- Неположительный результат не выдаётся как сопротивление.

Это инженерные фильтры для первичной оценки, а не подтверждённые метрологические пределы Tesla. CAN имеет задержки, усреднение и погрешности; результат включает динамический отклик, возможные вклады соединений и поляризации. Без квалификации частоты/задержек и условий результат нельзя называть стандартным DCIR или сравнивать с AC-IR/EIS. Температура и SOC живого блока могут отсутствовать. Приложение не создаёт нагрузку и не замыкает контакторы.

## CSV и источники данных

«CSV измерений» — одна строка на группу: сессия, источник, профиль, ёмкость, UTC захвата, V/I, собственные времена V/I, возраст, количество/разброс отсчётов тока, температура и SOC, когда известны.

«CSV оценки R» — строки всех групп, включая неподходящие: метод, R (пусто при отказе), код причины, обе исходные пары, ΔV/ΔI и интервал. Источник `demo` сохраняется; синтетика не переименовывается в физическое измерение.

Импорт принимает только этот формат, до 2 МБ и до 96 групп; смешанные сессии/профили и дубли групп отклоняются. CSV обрабатывается локально в браузере. Файлы не отправляются на сервер, не попадают в GitHub и не становятся публичными при просмотре демо. Сам пользователь может экспортировать/передать их отдельно.

## Демо

1. Демо запускается с выбранным профилем.
2. Сохранить A при синтетическом токе 0 А.
3. Нажать «Демо: переключить ток 0 → 50 А», дождаться обновления показаний.
4. Сохранить B, открыть «Оценка R», выгрузить CSV.

Кнопка изменения тока работает только в генераторе синтетических данных. На живом CAN этот серверный маршрут возвращает отказ. В рабочем оборудовании A/B могут захватывать только уже существующие, отдельно разрешённые и квалифицированные условия испытания.

## Windows/Linux и онлайн

Одинаковый код Python 3.10+ и браузерный UI. Windows: PCAN-Basic и драйвер PEAK; Linux: готовый SocketCAN. Запускатели создают виртуальное окружение без изменения драйверов и сетевых настроек. Локальный сервер слушает только `127.0.0.1` и начинает без CAN-подключения. PCAN запрашивает PASSIVE; аппаратный listen-only SocketCAN проверяется отдельно.

Онлайн-публикация содержит только HTML/CSS/JS, список профилей и синтетический генератор. У неё нет API для PCAN или удалённого управления реальной батареей. Для физического подключения скачивается локальный клиент. Это граница текущей реализации, а не скрытый облачный USB-мост.

## Проверенные первичные источники

- [Battery-Emulator legacy decoder, закреплённая ревизия](https://github.com/dalathegreat/Battery-Emulator/blob/83e124003adff5abe553478acb00672addd13347/Software/src/battery/TESLA-LEGACY-BATTERY.cpp): семейства ёмкости, наблюдаемые series-count, 0x6F2, 0x102 и 0x212. Декодер управления оттуда не копировался.
- [Документация разработчика Battery-Emulator: legacy S/X](https://dalathegreat.github.io/Battery-Emulator-Wiki/battery/tesla_model_s_x_2012_2020/): отделяет 2012–2020 от следующего поколения.
- [Исходный PiCanScanMyTesla](https://github.com/jetpax/PiCanScanMyTesla): исходный проект и предварительная температурная карта.
- [VoltDecode](https://www.voltdecode.cloud/): VSH относится к сопротивлению voltage-sense harness, а не к внутреннему R ячейки.
- [Keysight: методы сопротивления и зависимость от времени, SOC и температуры](https://www.keysight.com/blogs/en/tech/bench/2022/05/31/a-deeper-look-at-lithium-ion-cell-internal-resistance-measurements).
- [Tesla technical note через NHTSA](https://static.nhtsa.gov/odi/tsbs/2013/SB-10052460-6095.pdf): изоляция HV как отдельная величина.

Физическая совместимость и точность на конкретных батареях 60–100 кВт·ч остаются предметом аппаратной приёмки. Программная поддержка профиля и синтетический тест не заменяют её.
